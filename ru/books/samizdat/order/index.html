Запросить экземпляр

Единая точка запроса для всех авторских книг в системе самиздат 2.0.

Наличие, цена, язык, доставка и оплата подтверждаются лично. Отправка запроса не создаёт автоматического обязательства совершить покупку.

Что войдёт в запрос

прямой разговор, а не безликая касса

Язык

Предпочтительный язык физического экземпляра.

Количество

Один экземпляр для себя или дополнительные экземпляры в подарок либо для дальнейшей передачи.

Место назначения

Страна и город, чтобы стоимость доставки можно было рассчитать точно.

Контакт

Имя и email для личного подтверждения.

Назначение

Для себя, в подарок или для передачи книги следующему читателю.
