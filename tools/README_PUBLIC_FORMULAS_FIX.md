# Public Formulas Fix Plan

The first multilingual generation created the correct structure, but some formula pages were too compact, especially 03–06.

Correction rule:

- Public index cards must follow the Russian master page standard: short enough for a card, but dense enough to give a real semantic entrance.
- A card must not be only a title plus a slogan.
- Each card should include:
  - image
  - formula number
  - localized title
  - compact but meaningful description
  - strong formula line
  - button to open the standalone page
- Standalone formula pages must not feel like summaries or placeholders.
- Each standalone page should include:
  - image
  - main formula
  - full post text or a full literary adaptation
  - meaning
  - why chosen
  - research note

Priority fix:

1. Bring all multilingual /public/ pages to the Russian card-density standard.
2. Expand 03–06 in all languages.
3. Improve 01–02 so they do not feel shortened.
4. Keep Russian master pages as the reference standard.
5. After generator update, rerun `Generate multilingual public formulas` workflow.

Note: The current compact multilingual pages are acceptable only as a temporary scaffold, not as final public pages.
