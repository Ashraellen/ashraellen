Формулы

Лаканічныя фармулёўкі: адна думка — адзін дакладны ўдар.

Першая лінія

да ліній

Формула

Думка ўзнікае сама. Свабода пачынаецца там, дзе чалавек перастае станавіцца кожнай думкай.

думка / свабода / назіранне

Формула

Улада над сабой — гэта не ўлада над думкамі, а ўлада над увагай.

увага / улада / саманазіранне

Формула

Мы не выбіраем першую думку. Але можам выбраць, карміць яе ўвагай ці не.

выбар / увага / думка

Формула

Думка, з якой змагаюцца, атрымлівае сілу ад самой барацьбы.

барацьба / думка / энергія

Формула

Усвядомленасць пачынаецца не з цішыні ў галаве, а з фразы: "Я бачу, што гэтая думка ўзнікла".

усвядомленасць / цішыня / сведка

Формула

Усвядомленасць без цела — гэта канцэпцыя, якая назірае саму сябе.

цела / канцэпцыя / практыка

Формула

Цела гаворыць раней, чым розум паспявае прыдумаць тлумачэнне.

цела / розум / тлумачэнне

Формула

Цела — першыя дзверы да сябе, але не ўвесь дом.

цела / дзверы / шлях

Формула

Чалавек пакутуе не толькі ад трывогі, але і ад патрабавання не трывожыцца.

трывога / патрабаванне / пакута

Формула

Прыемны стан яшчэ не вызваленне. Часам гэта проста добра настроеная біяхімія.

стан / вызваленне / біяхімія

Формула

Практыка становіцца пасткай, калі спакой ператвараецца ў новага гаспадара.

практыка / спакой / пастка

Формула

Нават светлае перажыванне трэба назіраць, інакш яно хутка становіцца духоўнай цацкай эга.

перажыванне / эга / назіранне

Формула

Мінулае ўнутры чалавека існуе не як факт, а як успамін.

мінулае / памяць / факт

Формула

Чалавек часта пакутуе не ад падзеі, а ад версіі падзеі, якую працягвае насіць у сабе.

падзея / версія / пакута

Формула

Вызваленне — не стан, які нарэшце наступіў. Гэта момант, калі старая версія сябе перастала здавацца адзінай.

вызваленне / версія сябе / момант
