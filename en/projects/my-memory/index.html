MY MEMORY

Your memory should belong to you.

User-owned continuity infrastructure for long-running AI-assisted work.

The problem

A serious project can outlive a chat, a session, a model and eventually an AI provider.

When that happens, decisions become separated from their reasons, sources disappear from conclusions, commitments drift out of view, stale information competes with current state, and the user is asked to reconstruct the same project history again.

A successor AI should not have to guess what happened before it arrived.

What MY MEMORY does

MY MEMORY is an external project-memory layer focused first on Project & Decision Memory. It preserves the parts of long-running work that must survive beyond a single conversation or provider.

Project → Event → Decision → Reason → Person → Document → Commitment → Current State → Source

The AI participates in memory capture. The user owns the storage.

The system is designed to distinguish retained history from accepted current truth. Facts, decisions, reasons, assumptions, uncertainty and third-party statements should not collapse into one undifferentiated archive. Provenance matters, and later correction should supersede earlier state without pretending that the earlier record never existed.

External-user workflows

Two independent external-user runs completed with zero project-history retelling and zero facilitator help. This is directional evidence only, not a general usability claim.

What this evidence does not establish

  • Product-market fit or repeated target-user adoption.
  • Production security, scale or multi-user readiness.
  • Provider-neutral writable interoperability across all AI systems.
  • Long-duration reliability under production conditions.
  • Patentability, freedom to operate or a proven defensible IP moat.

The current evidence supports bounded continuity and recovery behavior. It is not presented as proof of a finished product.

Current product

Project & Decision Memory for people running real, multi-stage AI-assisted projects.

The initial target is work where losing context has a real reconstruction cost: founders, researchers, writers, creators, consultants and other people whose projects continue across many sessions and tools.
