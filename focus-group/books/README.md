# Focus Group Books

This folder is reserved for PDF reading copies shared with focus groups.

Suggested use:

```text
focus-group/books/<book-slug>/<file-name>.pdf
```

Example:

```text
focus-group/books/beton-pl/beton-pl-2026-03-21-pz.pdf
```

Important:

```text
- This repository is public.
- Any PDF uploaded here may be publicly accessible if someone has or discovers the URL.
- Do not upload private, confidential, or not-yet-public material here unless public access is acceptable.
- PDF files in this folder are not automatically added to sitemap.xml by the current HTML sitemap generator.
```

Recommended naming rules:

```text
- lowercase file names;
- no spaces;
- no parentheses;
- use hyphens;
- include language code and date/version when useful.
```
