Dark Style Lab

Изолированная страница для выбора типографики и компонентов основного тёмного сайта. Зелёная метка CURRENT означает существующее значение на сайте. Тёплая метка TEST — вариант для визуального сравнения.

Отвечать можно коротко по ID: «D-T05 лучше, D-T02 мелкий, D-B03 оставить».
